# Workspace Member Invitations Epic

Allow workspace owners and administrators to invite people as administrators,
deliver or copy secure invitation links, and manage pending invitations and
members. Proofplane remains authoritative for tenancy and membership while
Auth0 authenticates the invited person.

Full rationale, contracts, and decisions live in [spec.md](./spec.md), the
source of technical depth. Interface behavior lives in [ux.md](./ux.md).
